# 研究目标与边界

日期：2026-11-17。当前目标的简明维护入口；技术依据和失败分流详见 [路线决策报告](../docs/reports/项目目标与路线决策_20261117.md)。

## 主目标

**保留完整 MaleCNS 连接组，使其实际参与 RGB—神经活动—动作闭环，通过学习获得有效、可重复且依赖视觉的游戏行为，再逐步扩展行为复杂度。**

不是让纯像素策略替脑玩游戏；也不要求第一步就完成整个 DOOM。冻结脑外部读出是近期低新增成本方案，不是永久限定研究只能做储备池。

## 目标层级

| 层级 | 问题 | 达成需要什么 | 当前状态 |
|---|---|---|---|
| G0 工程 | 全图能否接入闭环？ | 全边与来源审计、逐 tic RGB/脑/动作记录 | 旧栈已具备；新任务训练接入待验 |
| G1 行为 | 参与系统能否学到视觉行为？ | 冻结行为改善、未训练/随机/开环/黑屏对照、独立训练重复 | 当前主攻，尚未达成 |
| G2 贡献 | 脑变换/真实拓扑有何额外作用？ | 匹配 frontend、合理重连 null、非地板比较与不确定性 | 未判决 |
| G3 脑内适应 | 脑内参数随经验改变能否帮助？ | 明确更新规则、冻结收益、无更新等匹配对照 | 现栈未实现 |
| G4 生理机制 | 是否复现自然视觉/运动/学习？ | 独立生理与行为数据验证 | 未验证 |

这些是结论层级，不是必须严格线性完成的时间表。G1 不蕴含 G2/G3/G4；G3 可在明确失败条件下作为 G1 的机制备选。

## 近期研究问题

- **RQ1（先做）**：缩短行为链后，现有完整冻结脑与外部读出能否获得可靠左右转角行为？
- **H1（系统比较）**：相同任务、受体前处理、读出容量及交互预算下，脑表示相对匹配 frontend 是否有改善？首轮对照用于分流，不以单 seed 小样本确认 H1。
- **H2（拓扑比较）**：有行为信号之后，真实图相对合理 null 是否有稳定贡献？旧粗 null 不保留目标入强度、自环及重复边数，不能作为最终确认性 null。
- **RQ2（条件备选）**：若证据指向脑路径瓶颈，少量有界正共享 gain 是否能改善？目前只是设计候选，无现成脑内学习能力。

## 近期成功怎么定义

以 [训练筛查协议草案](protocols/short-turn-learning-v1.md) 为待锁定入口：冻结 dev 至少 8/12、左右各至少 3/6，相对未训练和随机各多至少 4 次成功；正常视觉较黑屏多至少 4 次成功，并超过已观测的 train 开环 6/12 参考。可重复阶段结果还需至少两个独立训练 seed；确认集门槛在使用前另锁。

这是有限预算工程筛查，不是显著性保证。train 开环 6/12 不是 dev 的已测结果，后续应在同一 dev 条件记录预声明脚本，避免跨 split 冒充匹配比较。

## 近期不做

- 不自动续接旧 near_turn 三组队列，不为补齐表格投入 rewired 50k。
- 不先追求 CNN 高分，不并行搜索算法、GRU、前端与脑参数。
- 不把开放环可达性、82 项软件回归或 136 局无学习验收称为 G1。
- 不用放电/return 替代成功，不用未显著替代等效结论。
- 不先建设复杂多 agent 平台、API 应用或全图 GPU/BPTT 框架。

## 固定保护与变更规则

保留 166,700 神经元及约定集合间 25,582,938 条发布边；W0 与权威图只读。完整图不是字面活脑，LIF 参数、感觉映射和动作解码均须标明建模/工程假设。遥测只能算奖励、终止与审计，不能进入选动作。

改变目标/主线须写决策理由、证据、预算和停止条件；改变任务、奖励或动作须起新协议/版本，不覆盖已产生结果的定义。授权、来源与资源细则见 [AGENTS](../AGENTS.md)。
