# 短程任务有限学习筛查

状态：draft。研究协议 ID：short-turn-learning-v1（不是 CLI 已支持的协议值）。环境使用 malecns-short-turn-v1。此为 T015 待锁定方案，不授权训练。T010独立适配已实现并通过开发测试，但完整脑实机和正式总预算尚未验收/锁定；实际入口见[适配说明](../../docs/SHORT_TURN_TRAIN_ADAPTER_20261117.md)。目标与分流依据：[CHARTER](../CHARTER.md)、[路线报告](../../docs/reports/项目目标与路线决策_20261117.md)。

## 问题与比较

RQ1：现有完整冻结脑＋外部读出在真正短任务上能否学到依赖视觉的左右行为？首轮只有 real 与匹配 frontend；不同时加入 rewired、CNN、GRU、PPO 或脑内更新。

real：同受体采样/AGC-motion→完整冻结脑→512 signed hash、50/200ms trace、asinh/差分1536维→train-only固定校准→MLP DoubleDQN。frontend 同感觉前处理、1536维和读出容量，无脑动力学。固定脑不是脑内可塑性；同维也不等于同信息。

## 固定方法意图

- [环境](short-turn-env-v1.md) 的动作/奖励/拆分不变，无像素旁路与遥测动作控制。
- 两组共享训练 seed 计划和任务条件列表；训练 seed、环境 seed、投影 seed、重连 seed分别记录，未设重连 arm 不运行重连。
- train-only 校准在训练前冻结，eval 不更新校准、optimizer、replay；黑屏不重新校准。
- 宏转移 R=Σγ^i r_i，D=0（真终止）否则γ^k；target=R+D·Q。trunc 保留真实最终特征，reset 不跨局泄漏。
- 同一谱系预算累计，不把 resume 计成独立seed；新任务不加载旧任务 replay 或把旧50k当新任务已训练。

## 预算与评估意图（尚需 T015 闭合）

- 首轮每组最多30,000训练 game tics；checkpoint固定0/10k/30k。10k仅锁定4个dev链路检查，30k完整12 dev；0点需提供同条件未训练基线。
- 随机动作、预声明的两固定序列与未训练读出在同一12 dev上评估；固定序列分别报告，不能按左右选序列组合。已有train6/12是参考，不冒充dev实测。
- 正常与黑屏用同一冻结checkpoint/校准；拟在30k完整dev配对评估。是否在0点也做黑屏、每条件重复次数、随机RNG和总评估局数，必须在开训前确定。
- 校准、初始帧、真实验收、训练、评估与失败尝试分别记账。以game tics和墙钟双上限先到即停；不能仅提高wall_hours而保留更小step上限后误报训练量。
- 既有吞吐约2.46–2.95 tic/s只作量级参考，30k约2.8–3.4h不含全部额外成本；新短局吞吐尚未测。最终墙钟和总成本须由T020后锁定，不在本页承诺成功时间。

## 预声明筛查门槛

30k冻结dev：

1. 正常视觉至少8/12成功，左右各至少3/6。
2. 比同条件未训练读出、随机动作分别至少多4次成功。
3. 超过已有train开环6/12参考；同时完整报告同dev两个预声明序列。若预声明脚本达到或超过模型，不能以该任务声称可靠视觉行为，进入可辨别性复核，不事后重新定义通过。
4. 正常较黑屏至少多4/12成功，使用相同冻结校准与评估协议。
5. 报告成功耗时、max_progress、碰墙、动作分布、资源与完整性；return不是主判据。上述是工程决策阈值，不是统计显著性/功效保证。

首轮通过仅为单seed候选；至少两个独立real训练seed通过才支持可重复阶段结果。前两次不一致最多第3seed定位不稳定性，不无限重试挑阳性。confirm在配方冻结且单独锁定判据后使用，本协议不默认执行confirm。

## 停止与失败分流

- 来源、输入或配置不一致、非有限、资源未知/不足、STOP、墙钟到限：保存并停止，报告执行失败或中断，不写成方法阴性。
- real通过且黑屏退化：安排独立seed；不直接宣布H1/H2。
- frontend通过、real失败：最多一次train-only信息检查；按证据只换读出或只触发脑动态备选之一。
- 两组失败：一次任务/奖励/探索核验，仍失败停止配方，不扩大旧三组长训。
- real正常与黑屏都强：视觉贡献未建立，不升级任务为“已学会”。
- 不依据10k峰值挑checkpoint或改30k阈值；任何偏离先记决策，必要时新协议。
