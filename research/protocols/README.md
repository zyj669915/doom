# 实验协议

协议规定“要检验什么、如何执行、如何判断”，配置和源码负责实际执行。协议状态不等于用户授权。

| 协议 | 状态 | 用途 |
|---|---|---|
| [short-turn-env-v1](short-turn-env-v1.md) | implemented | 已有环境规范及历史验收版本边界，不包含学习器 |
| [short-turn-learning-v1](short-turn-learning-v1.md) | draft | real/frontend筛查仍待锁；已有独立训练适配不代表正式协议完成 |

## 状态与变更

- draft：设计未闭合，必须写出待锁字段；不能据此正式开训。
- locked：问题、配置/seed、对照、数据、预算、判定、停止及来源已固定；仍需本次用户授权和资源准入。
- implemented：相应范围已有实现，不自动代表真实验证或学习成功。
- completed / stopped：执行完成或停止；关联原始 run 和结果，不能覆盖最初方案。

产生结果后若改变任务/奖励/动作/划分，起新版本并记录理由；若只修边界程序，保存原 manifest，明确哪些验证仍适用、哪些尚未重跑。不为阳性结果事后改成功阈值。

新协议从 [协议模板](../templates/protocol.md) 复制，只填写必要字段。确认集使用次数和预算必须事先约定；确认失败不改名重新当未见数据。
