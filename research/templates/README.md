# 按需使用的科研模板

这些文件是空白格式，不是已批准任务、已预登记实验或已完成结果。复制后替换“待填写”，删去无关项；不要为了填表延迟实际研究。

- [task.md](task.md)：一项可独立交付的实现/分析工作。
- [protocol.md](protocol.md)：实验前固定问题、方法、数据、预算、判定与停止。
- [result.md](result.md)：实验后区分事实、解释和未完成。
- [decision.md](decision.md)：路线变化的证据、替代方案及重开条件。
- [handoff.md](handoff.md)：会话结束时的最小可继续上下文。

状态和下一任务统一维护在 [TASKS](../TASKS.md)；原始结果放run，模板不代替日志。文档内的示例值或占位符绝不能被当作真实实验成绩。
