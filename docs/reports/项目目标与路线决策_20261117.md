# 完整连接组游戏学习：目标、任务与路线决策

日期：2026-11-17。用途：明确项目要实现什么、下一次实验回答什么，以及什么结果才值得继续投入。本文是当前路线建议，不是新训练成绩或成功承诺。初次整理仅作分析；随后用户授权实现并验收短程任务，现已完成独立环境与软件测试，真实游戏验收首次被门禁拒绝、随后完整136局通过；名义左右均108tic可达，固定序列各50%、随机1/12。只通过环境验收，尚未验完整脑新任务执行与学习。实现状态与命令见[短程任务验收记录](../SHORT_TURN_ACCEPTANCE_20261117.md)。没有正式训练、修改冻结源码、checkpoint或权威脑图。

## 0. 决策摘要

**项目主目标：保留完整MaleCNS连接组，让其参与视觉—动作闭环，通过学习获得可重复、依赖视觉的游戏行为。**外部读出学习是起步方案，不是永久限定；脑内学习是候选研究阶段，不是当前已经实现的能力。不能用纯像素策略替脑完成任务，也不能把有放电、有梯度更新或跑满预算当作学会。

本轮建议：

1. **暂停自动续接旧near_turn三组长队列。**不追加旧real训练，不为了凑齐表格立即投入rewired 50k；旧50k完整val补测属于可选归档，不是新主线的前置门槛。
2. **把第一阶段任务改为真正短程的“看见左/右转角并进入正确支路”。**仍用ViZDoom、完整脑、同亮度和六动作，不把世界模型换成离线分类题。
3. **近期主攻：完整冻结脑＋现有1536维表征／MLP DoubleDQN，在短任务上做一次有上限的学习验证，同时只配一个匹配frontend诊断对照。**暂不同时更换读出、算法、前端和脑参数。
4. **唯一机制备选：保留全部节点与边，允许少量受约束、共享的脑内参数任务优化。**先验证算法与吞吐，不直接承诺全图BPTT、全边e-prop或接入FlyGM即可成功。
5. **可靠行为与拓扑贡献分两道门。**先获得可重复视觉行为，再做有辨别力的real/null比较；早期仍保留对照，但不把“完成旧队列”当成项目目标。

这不是认定冻结路线最好。选择它只因已有完整实现、前向可运行，短任务验证的新增成本最低。若预锁短任务也失败，必须按第6节转向，不把“再训一些”作为默认答案。

## 1. 目标层级与不可混用的结论

| 层级 | 要回答的问题 | 合格证据 | 当前状态 |
|---|---|---|---|
| G0 工程闭环 | 完整图能否被RGB驱动并控制游戏？ | 数据来源、全边保留、逐tic闭环、可复核记录 | 已实现 |
| G1 行为学习（当前主目标） | 连接组系统能否通过训练获得视觉行为？ | 独立训练重复、冻结行为改善、视觉干预与未训练/随机对照 | 未达成 |
| G2 结构贡献 | 完整脑变换/真实拓扑是否提供额外作用？ | 匹配frontend、合理null、非地板/天花板、有检出能力的比较 | 未判决 |
| G3 脑内适应 | 脑内参数或突触随经验改变是否有帮助？ | 可追溯更新规则、冻结后收益、无更新及打乱奖励对照 | 当前stage未实现 |
| G4 生理机制 | 模型是否复现果蝇的自然感觉/运动/学习机制？ | 生理与行为数据验证，而非仅游戏分数 | 未验证 |

G1达成不等于G2/G3/G4达成。固定脑＋可学习读出最多支持“完整连接组参与的学习系统”，不应称脑内突触已学会。未来允许脑内参数改变，也不自动具有生物合理性。长期目标不止储备池性能榜，但也不能把近期可实施验证全部跳过。

始终保留完整166,700神经元及约定集合间25,582,938条发布边。允许的候选变化须发生在独立版本/运行副本，不覆盖原graph.npz，不裁回路、不剪弱边或自环。策略仅接收RGB派生信号；坐标、角度、剩余路程可计算奖励/终止/审计，绝不用于选动作、脱困或恢复控制。

## 3. 为什么先改任务，而不是直接扩训或重建大脑

当前`near_turn`只改变出生位置，不改变通关终点：名义起点(1728,128)、转角中心(1920,128)、出口y=2048。剩余中心线路程约192+1920=2112地图单位，仍包含转向、纠偏、长直行和终点到达。

旧`progress = 1 - remaining/3712`以整条entry路线为分母。near_turn名义出生时已约43.1%，所以“到50%”不等于学会了一半任务。任何新短任务都应报告相对本局起点的路程改善、明确门槛和实际成功，而非直接沿用旧max_progress解释。

当前失败同时混合了感觉、转向、探索、长程回报和读出问题。把首个任务变短不是为了刷漂亮分数，而是降低一次失败的解释歧义，并让同样30k交互覆盖更多完整行为尝试。减少的是环境行为链长度，不是脑图规模。

## 4. 第一阶段任务建议：短程左右转角导航

**以下环境规格已通过独立`flyrl_turn`实现；原版136局真实环境验收完成，后续边界修复通过82项关联回归、未重跑实机。**学习器适配与4.3节行为门槛仍待锁定/验证，不能把环境通过当作学习成功。新旧任务另起版本，不得修改旧checkpoint所绑定源码或把新任务成绩与旧near_turn结果直接拼接。协议分别见[环境规范](../../research/protocols/short-turn-env-v1.md)与[学习筛查草案](../../research/protocols/short-turn-learning-v1.md)。

### 4.1 最小任务定义

- 沿用现有L形走廊和左右镜像、3335受体映射、同光照224、RGB-only策略、完整六动作及4tic决策；脑仍逐tic推进。
- 起点保留转角前一小段，首轮使用现有可见角度/位置扰动量级，不做多个难度笛卡尔积。
- **建议将成功门改为转角后短段：进入x∈[1792,2048]且镜像归一化y∈[512,2304]的区域。**名义中心线剩余约192+384=576单位，而非2112；不额外把“正确方向”作为标签输入策略。
- 建议每局上限280tic（8秒游戏时间），作为工程起点；必须先验证可达性，不假定一定足够。成功区跨步判定、镜像、真实终止/截断与最终帧必须有测试。
- 成功奖励、步成本、碰墙项和potential使用新的短程目标，保持时间折扣一致。达到短门是真终止；时间限是截断。不能只替换success字段而仍塑形到旧远端出口。
- 门槛和轨迹用引擎状态在环境内部判定，不能反向操控转向。任何人工可达性操作只看RGB，不能把特权教师轨迹混入自主训练成绩。
- 新train/dev/confirm采用分别预锁的布局条件，左右各半，实际WAD内容去重。建议12/12/24条件；旧test24不消费、不改名为新任务未见测试。仍是同类L形几何条件变化，不声称任意地图泛化。

### 4.2 最小任务验收，而非无限基线搜索

只验收一次：左右都能在时限内到达；未训练/随机与预声明固定/周期动作不会接近满分；奖励有限且不以停住赚得任务成功。固定策略过强并不使模型错误，但会削弱该任务作为视觉学习证据，应在正式训练前一次性处理，而不是事后改标准。

若280tic不可达，仅允许先在环境验收阶段修订一次时限或成功门，写明原因并锁定。若任务在小改后仍不合适，就停止这一设计，不用全脑训练帮环境调试。不要求先训练一个高分CNN才能验收任务。

### 4.3 建议的行为门槛（须在新实验开始前锁定）

- 首轮筛查：训练后冻结dev至少8/12成功，左右各至少3/6；并比同条件未训练读出、随机动作分别至少多4次成功。
- 视觉依赖：使用同一冻结校准与读出、从episode开始黑屏，成功数较正常视觉至少下降4/12。黑屏操纵属于输入干预，不是生理视觉证明；固定scramble不必作为首轮必跑项，更不能把它当图拓扑null。
- 可重复阶段结果：至少两个独立训练初始化都满足上述行为筛查；若前两次不一致，最多再加一个seed定位不稳定性，不无限重试挑阳性。最后对选定、冻结的配方进行一次独立confirm评估。
- 8/12及4次差值是工程决策阈值，不是功效计算或显著性保证。报告逐条件和逐seed结果、区间；12case不是12个训练重复。确认集门槛/样本数也须在使用前单独锁定，不由dev表现反推。
- 短程成功只是第一块行为能力。之后取消短门、延长目标到现有出口，再移至entry；迁移不成功时不能仍称学会完整走廊。

## 5. 路线选择：一条近期主线，一条机制备选

### A：近期主线——冻结完整脑，先建立短行为

复用已有1536维全脑signed-hash、50/200ms双trace、MLP DoubleDQN，首轮不同时增加GRU、换PPO、换前端和调脑工作点。它减少新增变量，而不是保证原表征最优。完整脑是策略获得任务信息的路径，不增加像素旁路。

只增加一个匹配frontend对照：同受体采样/前处理、同1536维、同读出容量、同任务/奖励/动作/校准/样本预算，无脑动力学。它是低成本的分流诊断，不要求先获得CNN最高分。两组同维不等于同信息；frontend胜出只能定位到当前脑变换／投影／动态工作点组合，不能唯一归因为原连接图或视网膜。

建议首轮每组同一训练seed、累计最多30k game tics，保存0/10k/30k固定点；10k只用4个锁定dev条件检查链路，30k用完整12条件。若没有行为改善，不自动扩到100k或再加seed。real通过才进行独立seed重复；frontend通过与否决定失败分流，而不是替代脑主线。

### B：唯一机制备选——完整拓扑上的少量受约束脑内参数

只有第6节条件触发后才实施。建议从少量按已发布神经元类别绑定的正源增益开始，其他参数保持基线：

`W_eff(i→j) = g[class(i)] × W0(i→j)，g>0且有界。`

W0及原始图保持只读；所有原边、零边和符号保留，不增加捷径边。少量类别选择与边界应在train-only设计阶段固定，并记录类别覆盖；类别共享不是删掉其他回路。不要首轮同时优化增益、偏置、阈值、前端和读出结构。

这能改变脑内动力学，但当前FrozenBrain内核不支持此更新：需要独立适配、数值测试及参数优化机制。**参数少只减少可学自由度，不减少完整脑前向代价，也不自动解决信用分配。**零阶成对扰动可避免改成可微仿真，但每次仍需昂贵闭环；若使用代理梯度则需实现对应导数与稳定性机制。

实施前必须具体锁定参数数量/边界、优化规则、训练目标和总前向预算，并在微型全边参考模型上验证更新确实改变目标。参考原型可限制2–8个共享增益；这是工程起点，不是已验证最优或最终cell_type模型。若原型不能在限额内学到最小任务，就不移植到全脑，不先写数周框架。

一旦改变脑参数，旧replay特征与旧归一化可能过时；不得继续当作当前表征的离策略样本。需冻结一套明确更新阶段、重新校准/采集或具备可验证的重编码机制，不能把旧DQN缓存直接续上。参数搜索用训练布局，不能用dev/test选脑参数。收益须与同预算“只训读出”比较，不把更多调参成本算成拓扑收益。

## 6. 根据结果做什么：不把所有失败都解释成预算不够

| 新短任务观察 | 可以学到什么 | 下一步；只允许有限调整 |
|---|---|---|
| real通过且有视觉依赖，独立seed也通过 | 完整连接组参与的系统可获得此短行为 | 冻结配方，跑confirm；再扩任务及real/null归因。不能先宣布真实拓扑有益 |
| real与frontend都通过、差异小 | 任务/训练可工作，但当前没有脑增益证据 | 向长任务迁移；若要检验H1需合理区间/等效界，不能拿不显著当等效 |
| frontend通过，real不通过 | 同受体输入和学习器组合在无脑路径可用；问题收窄到当前脑表示路径 | 最多一次train-only任务信息检查；若指向读出压缩，换一个已实现读出；若指向脑动态，触发B。不得同时改两者 |
| 两组都失败 | 未定位脑问题；任务、奖励、探索/学习器或输入均可能 | 一次环境/奖励/探索核验，非先跑完rewired；若仍失败，停止此配方，比较受约束脑内学习原型，不扩大三组长训 |
| real通过但黑屏也同样通过 | 未建立视觉贡献；可能有开环/动作历史捷径 | 不算阶段成功，检查任务可辨别性；不以过关数继续升级难度 |
| dev通过，confirm或另一个训练seed失败 | 学习不稳或条件泛化不足 | 最多第3个seed做不稳定性诊断，不挑峰值；先修稳定性，不宣称成功 |
| 资源停止、非有限、来源不一致 | 工程条件不满足，不是方法阴性 | 保存并停，不降低余量、不混入不等预算比较 |

“信息检查”仅在失败指向时触发：使用train-only有限轨迹，预先选择一个与左右转向相关的标签做诊断，标签不进入策略；设置相邻帧/episode泄漏控制。可解码不等于可控制，不可解码也可能是检查器能力不足。禁止把这一步扩成无界视觉分类排行榜。

## 7. 成本与可行性：能运行、能学会、值得运行是三回事

### 当前栈与硬件

现有50k real累计训练约16972秒，平均约2.95 game tic/s，含训练初始化/校准等，不能外推为纯脑内核速度。按该量级30k约2.8小时/real谱系，12条件×280tic一次全脑冻结评估约19分钟，均不含新任务重置/资源波动等额外开销。原测2.46tic/s可作为较保守参考，不承诺短局有同样吞吐。

第一轮先付出一个real30k和一个frontend30k，加必要冻结评估；real通过才付第二个独立谱系。最多3个real谱系是上限，不是必须跑满。预算不足时减少尚未启动的实验范围，不降低系统保护，也不把中断结果当完成。

RAM 3GiB系统余量及任务预算是启动约束，不是科研主目标；不反复查资源来替代设计。任务/纯测试/文档可以在不载全脑时准备，只有到真实执行关口才重新门禁。不擅自关闭其他程序、不改系统设置。全脑当前在CPU，换用CUDA小读出不等于全脑加速。

### 为什么不能直接说“加e-prop就好”

每条float32逐边数组约97.6MiB；k条资格迹约97.6k MiB，尚未计图、状态、梯度和优化器。一个float32逐神经元状态约0.636MiB；朴素时间展开若保存c种状态、B个样本、T个0.1ms步骤，内存约`4×B×c×166700×T`字节。1秒神经时间T=10000，单状态量已约6.67GB（十进制），反向另计。

e-prop不需要保存整段时间历史，但逐边资格迹/学习信号与计算仍有代价；稀疏活动实现也不同于逐步全边扫描。截断、重计算、检查点和共享参数可改变资源需求，因此不能仅凭8GB显存断言绝对不可行，也不能由“数组放得下”推导训练实用。

### 文献能支持什么，不能支持什么

本次对本地FlyGM、e-prop仅限相关方法页核查，不声称全篇复核或复现：

- [FlyGM本地PDF](../../../reference/papers/FlyGM_WholeBrainConnectome_Locomotion_arXiv2602.17997.pdf)，PDF第4、13页：固定连接权重，训练编码/门控、共享更新MLP、神经元描述符与解码，使用专家模仿后PPO；它是连续状态图模型，不是当前硬阈值LIF，也不是证明本项目只需解冻权重。
- [e-prop本地PDF](../../../reference/papers/eProp_RecurrentSpikingNetworks_Bellec2020.pdf)，PDF第2–4、13页：资格迹、伪导数和近似学习信号，奖励形式使用actor–critic。当前Numba硬阈值、只读权重、外接DoubleDQN没有这些组件；没有autograd不妨碍手写规则，但规则还未实现。

上述论文不保证当前任务阳性，也不验证本文提出的少量类别共享增益。11月1日文档中的“已知原因”“释放计算潜力直接处方”“A6只依赖像素统计”等强结论不作为本轮决策的已证事实。

2. **随后T010已实施：**新增独立短任务训练适配，支持train/无优化accept/冻结dev评估/严格快照恢复，并通过开发测试；没有真实全脑或ViZDoom执行，见[适配验收](../SHORT_TURN_TRAIN_ADAPTER_20261117.md)。下一件工作是少量完整脑新任务资源/吞吐验收与总预算锁定；不重写三组框架，不立即实现脑内学习。旧stage不能通过改参数直接复用为新协议。
3. **适配验收后：**锁定布局、行为阈值、预算和源码；资源通过才做A路线real/frontend一次筛查。环境验收通过不代表完整脑已经可以学会。
4. **首轮判决：**按第6节继续、有限纠偏或触发B；不自动补齐所有旧路线，不自动增加训练时长。

不许诺几天或几小时“必然玩会”。能承诺的是每次投入有一个明确问题、一个有限预算和一个失败后的决策，不再用维护队列或不断诊断代替项目推进。
