## 二、原版是什么样（作者交付的东西）

作者 Alex Wormuth 基于 MaleCNS v1.0 连接组搭了"果蝇玩 Doom"：
- 输入：游戏画面 → 4146 个感光点（亮度采样）→ 注入果蝇脑
- 大脑：LIF 仿真，信号在 16.6 万神经元连接组里传播（固定权重）
- 输出：读脑内 14 个神经元 → 转成转向/前进/开火

**作者自己记录的事实（证据：`outputs\doom\validation.json`，作者亲笔）**：
- `biologically_validated: false`（未经生物学验证）
- **10 个真实运动/口器读出（MN9×2、DNa02×2、MDN×4、DNp09×2）在所有条件下 `spikes: 0, rate_hz: 0.0`** —— 一个脉冲都没有
- 作者原话（interpretation 字段）："运动/口器读出保持沉默。这不是成功游戏控制、真实视觉或学习的证据"
- 游戏动作实际由工程 BCI 驱动（DNp20 R−L→转向、DNpe017→前进+开火）
- 作者 README 原话："These are engineered controller assignments, not established natural motor functions"（工程控制器分配，非自然运动功能）；"Status: live experimental training, not demonstrated learned survival"（未证明学会生存）；v1–v6 学习实验全部失败

**结论**：原版 = 果蝇脑当"游戏手柄"用，不是"果蝇在玩"。会动，但不动脑。

- **判断**：固定权重 LIF + 亮度饱和视网膜 + 恒定偏置，"会动不会玩"是物理极限 → **行为提升必须靠训练**（与作者 v1–v6 全失败的动力学根源相同，本项目独立复现）

## 四、关键结论汇总

1. 连接组数据是真的、没被修改（哈希一致）
2. 原版"大脑→游戏动作"从没接通（运动读出 0 放电，BCI 旁路），**这是作者自己承认并记录的事实**
3. 我们把真实运动通路接通了（MN9 驱动行为），但**固定权重下行为提升不了**
4. 参考全世界的做法：**所有让果蝇脑"会玩"的项目都是经过训练的** → 训练是必经之路

## 六、常见问题解答（Q&A）

**Q1：需要学习才能正常玩游戏吗？**
A：是。所有"会玩"的版本都经过训练（见第五节）。未训练的固定权重连接组 = "会动不会玩"，这是必然的。

**Q2：原版能放电吗？**
A：**运动神经元不能**（10 个读出 0 脉冲，作者自己记录）；**BCI 用的 4 个神经元能放电**（DNp20/DNpe017，被当游戏手柄用）。两者要分清。

**Q3：是否修改了果蝇大脑？**
A：**连接组数据没动**（16.6 万神经元/2558 万突触逐字节一致，git diff 行为零差异）。改的是**仿真参数**：权重缩放、放电阈值、板层偏置、解码方式（哪个神经元接哪个按钮）。类比：没改电路图，只调了电压和接线端子。

**Q4：一定要训练吗？人类为什么不用？**
A：仿真果蝇脑是"**死脑**"：固定权重快照、无学习机制、无感觉-运动闭环。人脑是"**活脑**"：进化+个体发育已把视觉/运动/奖励系统打磨好，而且**人玩游戏时脑就在实时训练**（多巴胺奖励、运动学习）。人的"不用训练"是错觉——训练从出生前就开始了。

**Q5：训练之后会改变大脑结构吗？**
A：改**突触权重**（连接强度），不改**连接组拓扑**（谁连谁）。alpha-fly 原话："没加或删连接，没翻转符号"。权重可塑性 = 学习。极端长期才涉及结构可塑（突触生成/修剪），主流方法（含所有参考项目）都是权重级。

## 七、doomfly-rl 蒸馏训练（2026-09-29 完成首轮闭环）

### 方法（对应用户指派的 doomfly-rl 思路，本机缩小版）
1. **PPO 老师**：普通 Doom 智能体（MLP 策略，观察=24×32 降采样灰度 768 维，12 离散动作=转向3×前进2×开火2，奖励=击杀×10−扣血×1），30k 步 ≈ 17 分钟（CPU）。学习曲线：2.0 → 中段峰值 3.7，后期 1~3 波动（3 局评估方差大；小训练量上限）。
2. **蒸馏**：老师玩 8 局（1680 帧）→ 每帧跑**真实果蝇连接组**（scale=1.5, bias=6, thresh=−48）→ 取 14 个读出神经元放电计数作特征 → 训练读出层 Student(14→128→64→12) 交叉熵 60 epochs（acc≈45.7%）。
3. **闭环评估**：3 seeds × 210 tics，combat_survival，对比三配置。

### 结果（evaluation.json / three_config_compare.png）
| 配置 | 平均击杀 | 平均存活 tics/210 | 局末健康 |
|---|---|---|---|
| baseline（作者 BCI，scale1/bias12） | 1.00 | 192 | −5 |
| random（随机读出层+修复脑） | 0.00 | 205 | 8 |
| **distilled（蒸馏读出层+修复脑）** | **1.00** | **210（满局）** | **80** |

### 结论（诚实版）
- ✅ **流水线跑通**：从老师到果蝇脑特征再到读出层闭环，全链路可复现。
- ✅ **明确进步**：蒸馏果蝇脑"学会活着"——满局存活 + 健康 80 vs 原版 BCI −5；实机对比 GIF 见 outputs\doom\distill-v1\（distilled_seed41029.gif vs baseline_seed41029.gif）。
- ⚠️ **击杀未超越**：kills 1.0 与原版持平。原因：老师本身只到中等水平（小训练量）、14 维读出特征信息少（MDN/DNp09 几乎不放电，实际只有 MN9/DNp20/DNpe017 有信号）、12 动作离散粗。
- 下一步候选：老师加大训练量+动作细化、特征加历史窗口（5 帧→70 维）、蒸馏"动作分布"而非 argmax、按 doomfly-rl 二阶段继续。


### 首轮结果的复盘诊断（2026-09-29 追加，回答"真有提升吗/连接有问题吗"）

- **物理连接通但通道窄**：14 读出中仅 5 个实机放电（DNp20_L/R ~93%、MN9_L/R ~56-66%、DNa02L 50%），其余 9 个 <1.3% 近乎哑火。
- **教学连接弱**：学生 argmax 对上老师动作仅 34%（老师自身确定性仅 44%）。
- **根因 = 老师退化**：PPO 老师 30k 步后 argmax 策略 630 帧全为单一动作（右转+前进+不开火），即"乱转活着"，从未学会战斗 → 蒸馏无米之炊。

## 十、脑 vs 无脑消融（2026-10-15，关键阴性结果）

**实验**（ablation_brain.py，500 帧，distillable 老师，combat_survival，seeds 41027/41028）：学生输入分别取 A=真实脑 top32 活动 / B=直接感光值 PCA→32 维（无脑对照）/ C=打乱连接组脑 top32（结构破坏对照），同结构（线性 + 2 层 MLP）、5 分割 seed、平衡准确率。

| 臂 | 单帧 linear | 单帧 MLP | 5 帧窗 linear | 5 帧窗 MLP |
|---|---|---|---|---|
| A 真实脑 top32 | 0.137±0.017 | 0.158±0.016 | 0.126±0.032 | 0.164±0.041 |
| B PCA 像素 32 | 0.115±0.025 | 0.163±0.032 | 0.109±0.022 | 0.163±0.042 |
| C 打乱脑 top32 | 0.136±0.023 | 0.159±0.030 | 0.134±0.035 | 0.146±0.008 |
| 脑 vs PCA 增益 | +0.022/+0.026 | −0.005/+0.045 | +0.017/+0.019 | +0.002/+0.056 |
| 脑 vs 打乱 增益 | +0.001/+0.011 | −0.001/+0.027 | −0.008/+0.035 | +0.018/+0.041 |

（多数类基线 0.356）

**结论（诚实版）**：真实脑活动相对直接像素特征**无稳定增益**（linear 略好 ~+0.02，MLP 无差异），打乱脑与真实脑几乎不可区分——**在当前读出配置下，166,700 神经元连接组变换没有提供超出前端编码的可解码信息增益**。这实证了《进展与瓶颈》报告 3.2 节提出的"伪行为"风险：成绩可能主要来自人工前端编码器 + 读出 MLP。走廊任务的三臂消融（corridor_ablation.py，v6 老师）为下一步验证。

## 十一、走廊避障任务（2026-10-16~17，当前主线）

按《进展与瓶颈》报告建议，任务降级为果蝇适配任务 Tier 1：**光流走廊避障**（task-selection.md 定稿规格）。

**场景**（corridor_arena.py）：L 形走廊（入口直段 → 右转 90° → 出口段），无敌人/弹药/血包；纯 UDMF 地图无需 ACC 编译器；奖励 shaping 在 Python 侧（撞墙 −0.15、进度 +0.01×Δd、出口 +10）；episode 上限 2000 tics。

**老师**（corridor_teacher.py，PPO）：观测 = 24×32 灰度 + 帧差分（1536）+ 朝向 cos/sin（2）= **1538 维**（朝向对应果蝇中央复合体航向表征）；动作 = 转向 {−15°,0,+15°} × 前进 {0,20} = **6 类**；cosine lr 3e-4→3e-5。

**训练迭代 v3→v6**：

| 版本 | 时间 | 结果 | 判定 |
|---|---|---|---|
| v3 | 10/16 22:47（194,560 步） | 出口率 ~0.95-1.0，撞墙率 0.02-0.05，偶发 487 次撞墙局 | 基本学会，不稳 |
| v4 | 10/17 13:14（194,560 步） | 出口率 1.0，撞墙率降至 0.0026，末局零撞墙 | 达标 |
| v5 | 10/17 14:26（112,640 步早停） | **失败**：奖励长期为负（−28~−251）、出口率 0、每局撞墙 48-150 次 | 惩罚/变更过强导致退化 |
| **v6（当前最优）** | 10/17 16:08（184,320 步） | 4 万步即出口率 1.0，撞墙率 0.0001-0.0003，均值奖励 ~44.5，末局全零撞墙 | **恢复弱惩罚 0.15；640×480 云 VM 同配置 argmax 100% 成功** |

**任务规格成功线**：出口率 >90% 或 撞墙 <5/千帧 → **v6 老师层达标**（出口率 100%、撞墙 0.2/千帧）。

**诊断记录**：trace_corridor_win / trace_corner_win（10/16 23:38-40）证明"只会直行的策略"在转角卡死（pos=(2030,128)、剩余距离 d=1554、进度 55%、每帧 WALL）；quick_check（10/17 14:02）抓到同类退化行为（5 局全卡墙角、maxprog 0.55、动作恒为直行）——即 v5 失败模式的直接证据。

**下一步（脚本已就绪，未跑）**：① evaluate_corridor_teacher.py —— v6 老师 argmax 确定性终验（5 seeds × 20 eps × 2000 tics）；② corridor_ablation.py —— 走廊三臂脑 vs 无脑消融（v6 老师 500 帧，线性+MLP，配对增益判定）；③ 之后按 task-selection.md：采集脑活动+老师标签 → 学生蒸馏（32×win→64→6）→ 学生闭环 vs 三对照。

## 十二、外部评审与认知校准（2026-10-17）

> 本节记录三份外部 AI 评审对本项目的判断，以及据此对项目定位、上限与路径的认知校准。三份评审基于项目不同时点的状态（老师 v1/v4 时期 + 走廊任务前），与当前状态核对后写入。

### 12.1 三份评审的共识

1. **前期工程已完成、难度最高的一部分已经拿下**：真实连接组接入 ViZDoom、可复现的冻结脑基线、多轮迭代的 PPO 老师、经实测验证的视觉输入与读出接口，以及明确识别出的四类关键问题（视觉编码、神经元动力学近似、读出信噪比、任务适配度）。
2. **当前最高优先级不是继续修补输入或增加训练时间**，而是用最小成本证明"果蝇脑到底有没有贡献"（脑 vs 无脑消融 + 打乱/随机对照，控制输入、训练预算、学生结构、评估场景）。
3. **任务必须适配果蝇视觉能力**：Doom 战斗需要静态识别与远距离规划，果蝇不擅长；光流走廊避障（本项目已选）或 loom 触发闪避/反射开火的简化 Doom 更合适。
4. **核心假设未被验证**："会玩 Doom 的老师一定能教好果蝇脑"——高击杀≠好老师（本项目三老师终验已独立证实），蒸馏质量还取决于老师可迁移性、读出信息量、时间对齐与闭环稳定性。
5. **指标口径要严格**：离线可分性（37.5% 等）≠ 游戏能力；8.3% 是理论随机基线、5.0% 是随机神经元实测，二者不可混用；单次击杀/离线分类不准当"学会"的证据。
6. **仿真速度 0.6–0.9 s/帧是规模约束**：先做小样本、可复现的验证，不要直接启动大规模实验。

### 12.2 项目定位再声明（校准后）

本项目不是"让果蝇脑独立征服 Doom"，而是——**在严格对照下，检验冻结的雄性果蝇全脑连接组能否为行为学习提供可重复、可解码的增益**；在此基础上逐级完成"蒸馏学生 → 简化场景闭环 → 复杂度泛化"。前期全部工程（审计、修复、老师、接口、消融）都服务于这一检验。

**三条方法路线（评审归纳，与本项目对应）**：
- **A 连接组约束网络**：保留连接结构、训练允许的参数（FlyVis）——可作视觉前端/脑内参数训练的远期选项；
- **B 行为克隆**（本项目学生路线）：老师→状态-动作数据→学生预测——简单稳定，但学生无法处理训练数据之外的局面，闭环测试不可省略；
- **C 端到端 RL**（本项目老师路线）：直接按游戏奖励优化——可扩展到学生读出层。

### 12.5 后续目标与任务（按优先级，每阶段预定义成功指标与失败决策）

- **P0 最短路径验证连接组贡献**：
  1. v6 老师 argmax 确定性终验（5 seeds × 20 eps × 2000 tics，evaluate_corridor_teacher.py 就绪）；
  2. **走廊三臂消融**（corridor_ablation.py 就绪）：真实脑 top32 / 打乱脑 / PCA 像素，同结构（线性+MLP）、配对增益、≥3 seeds；
  3. 失败决策：若走廊消融仍阴性 → 明确结论"当前输入+读出配置下连接组无增益"，转向输入升级（ON/OFF 运动通路、对比度）或读出选择（按 2025 神经元类型注释定向挑选）；若阳性 → 进入 P1。
- **P1 蒸馏闭环**：采集走廊脑活动 top32 + 老师标签（覆盖场景与种子）→ 学生蒸馏（32×窗口→64→6 动作，保存动作分布而非 argmax）→ 学生闭环 vs 三对照（随机/打乱脑/PCA 像素）+ 老师对照；成功线 = 配对增益 + 平衡准确率 + 闭环成绩，不把离线可分性当学习证据。
- **P2 泛化**：闭环达标后逐步加复杂度（loom 闪避/简化射击 → 移动敌人 → 复杂地图），检验跨场景维持表现。

### 12.6 项目上限与实现路径（分层判断）

- **上限分层**：
  - L1 简化任务中连接组产生可重复、优于合理对照的行为 —— **现实可行**（消融 + 最小任务，近期可达成）；
  - L2 蒸馏学生在 Doom 简化场景达到老师表现比例 —— **可行**，取决于 L1 结果；
  - L3 冻结全脑自主、稳定、跨场景玩原版 Doom —— **无充分依据，不承诺**（与上游 README 立场一致：当前候选版本未通过视觉、条件学习与生存验证关卡）。
- **实现路径**：连接组贡献验证 → 果蝇适配任务 → 老师训练与数据采集 → 学生蒸馏 → 闭环评估 → 逐步增加 Doom 复杂度；每阶段预定义成功指标与失败后的决策条件。
- **最终价值**：即使无法独立征服原版 Doom，项目仍构成完整且有研究价值的课程成果——真实连接组×游戏环境的整合 + 用严格消融回答"连接组能否为行为学习提供增益"这一核心问题。最优策略不是放弃 Doom，而是先完成可验证的最小成功版本，再用实验证据决定距离完整 Doom 还有多远。
