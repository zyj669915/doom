# 果蝇输入/输出接口选择方案（学生侧定版）

> 板块范围：游戏画面 → 果蝇视觉输入（输入接口）→ 连接组 → 读出神经元（读出接口）→ 学生 MLP → 12 动作（输出接口）
> 依据：外部 AI 审计（第三节输入端 4 条 / 第四节输出端 4 条）+ 我们全部实测（视觉 6 变体 / 读出 2 轮实验 / 分组实验 / input_probe）+ 老师板块已完成的三老师（highscore/stable/distillable）
> 原则：不推翻已验证最优（v4_agc_motion、top32/ABC96）；补足未验证项；一切以"脑读出一致率 + 闭环"为最终判据。

## 二、方案（接口定版三步）

### 第一步：输入接口诊断与定版（~1h）

保留 v4_agc_motion 为输入基线，执行 **6 类诊断画面测试**（复用 input_probe 机制，用 top32 读出 + 视觉贡献指标）：

| 测试画面 | 要验证的能力 | 通过标准 |
|---|---|---|
| 静止固定背景 | 基线活动稳定 | 读出活动方差小 |
| 整体亮度增减 | 亮度响应存在 | vis 贡献 ≥+35%（已达标） |
| 目标左移/右移 | 运动方向可区分 | sep_acc ≥0.15（v4 当前水平） |
| 目标由远及近 | 接近响应 | 读出活动随距离单调 |
| 玩家转向背景移动 | 自转抗干扰 | 自转污染 ratio ≤1.5× |
| 敌人与背景同动 | 目标提取 | 敌动响应 > 背景动响应 |

**分支**：
- 全部通过 → 输入定版 v4_agc_motion
- 方向不可区分 → 脑侧感光层加 ON-OFF 双通道（T4/T5 生理语义）
- 自转污染严重 → 加 4 帧堆叠或自转补偿（脑侧）
- 时间尺度：确认 50ms/帧脑仿真与 16.7ms 游戏帧映射（记录帧号对齐表）
- R8 颜色通道：**记录为工程简化不实现**（Doom 信息主要在亮度/运动；若诊断显示颜色信息必要再实现）——待你确认

### 第二步：读出预筛——老师 × 读出集合 → 脑读出一致率（~2-3h，核心实验）

```
三老师（highscore / stable / distillable）
    × 三读出集合（author14 对照 / top32_raw / ABC96）
    → 采集老师行为标签（每老师 1 episode，~600 帧）
    → 全脑仿真得到脑活动
    → 读出层解码一致率
    → 选出"行为可被脑解码"的最佳（老师，读出）组合
```

这一步直接回答两个悬而未决的问题：
1. **强老师是不是好老师**（highscore 迁移率 0.26 的"记忆选手"行为能否被脑读出解码？预期解码率低）
2. **读出该选哪些**（top32 数据驱动 vs ABC96 生理混合 vs author14 作者原始）

**验证标准**：预筛一致率 ≥60%（v1 的 34% 翻倍目标）；若 <60% 则判定"当前读出接口信息不足"，回到第一步查输入。

### 第三步：输出接口定版 + 正式蒸馏（~3-4h）

- 学生 MLP 输入维度：按第二步胜出的（读出集合 × 时间编码）定：单帧 top32=32 / ABC96=96；窗口模式 × 帧数
- 时间编码：正式大样本（≥5000 帧）下重试单帧/5帧 concat/mean/trend/10f——若仍不如单帧，定版单帧
- 学生结构：输入→256→128→12（保持，维度对齐），动作与老师 12 类一致
- 闭环验证：600 tics × 3 场景 × 5 seeds，指标与老师协议完全一致（击杀/存活/健康/弹药效率/一致率）——可直接与老师对比
- 防泄漏检查：学生输入只用脑活动，无敌人坐标/游戏状态标签

## 三、执行结果与定版结论（2026-10-12 完成）

### 环节一：输入诊断（input-diagnosis/results.json，6 类合成画面 × top32 读出）

| 场景 | 指标 | 结果 | 判定 |
|---|---|---|---|
| S1 静止 | 活动稳定 | mean 2.35 / std 2.51 | 噪声大（std>mean，读出本身不稳定） |
| S2 亮度 | 3 类亮度分类 | 0.667（随机 0.333） | 亮度信息存在，响应弱（+6.9%） |
| S3 方向 | 左移 vs 右移 | 0.625（随机 0.5）质心 2.31 | 运动方向可区分 |
| S4 接近 | 尺寸→活动相关 | 0.291 | 接近响应弱 |
| S5 自转 | 污染比 | 0.971 | 自转几乎不污染（AGC+差分鲁棒） |
| S6 敌我同动 | 目标增益 | 1.089 | 目标提取弱（差分局限） |

定版：输入 = v4_agc_motion（方向/亮度/自转抗性达标）。接近与敌我同动记录为已知边界；不做 ON-OFF 双通道（方向已可分，收益不确定）。R8 颜色不实现。

### 环节二：读出预筛（readout-prescreen/results.json，3 老师 × 3 集合，150 帧/老师）

| 老师 | 集合 | 1f | 平衡1f | 5w | 多数类基线 | 判定 |
|---|---|---|---|---|---|---|
| highscore(记忆) | author14/top32/ABC96 | <=0.133 | <=0.117 | <=0.300 | 0.253 | 行为不可被脑解码 |
| stable | top32 | 0.367 | 0.272 | 0.333 | 0.240 | 唯一超基线组合 |
| stable | ABC96 | 0.267 | 0.267 | 0.133 | 0.240 | 超基线 |
| distillable | author14 | 0.300 | 0.189 | 0.233 | 0.440 | 虚高（类不平衡） |
| distillable | top32/ABC96 | <=0.333 | <=0.188 | <=0.200 | 0.440 | 低于基线 |

关键结论：
1. highscore（记忆选手）行为几乎不能被视觉脑活动解码（平衡准确率<=0.117）——"强老师=好老师"再获实证，三老师取舍 = stable 或 distillable。
2. stable×top32 / stable×ABC96 是唯一超过多数类基线的解码信号（平衡 0.267-0.272 vs 随机 0.083）——真实可解码信号存在，但距 60% 目标远。
3. 单次 150 帧采样噪声大（两次 rollout 结果不同）——正式蒸馏需大样本。
4. 一致率低 = 输入坏？否：环节一已证输入正常；瓶颈是读出活动信噪比低（黑屏放电/静止波动）+ 12 类单帧表达局限。

定版：读出集合 = top32 与 ABC96 双保留（stable 下均超基线）；老师首选 stable（平衡解码 0.272），distillable 为行为更简的备选；highscore 淘汰。

### 环节三：输出接口（output-check/results.json，10 帧实证 + 静态审查）

| 检查 | 结果 |
|---|---|
| 帧号连续性 | 0-9 连续无跳帧 |
| 同帧对齐 | pixels→brain→特征→标签→动作同一循环同一帧，无未来信息 |
| 维度表 | feat = n_readout × win（author14×5=70 / top32×5=160 / ABC96×5=480），StudentV2 通用 |
| 防泄漏 | 学生输入只含读出神经元 spike counts，无游戏内部变量 |
| 动作空间 | 12 类与老师训练完全一致 |
| 已知问题 | distill_v2.collect 的 ppo 分支仍用旧 768 维 obs 喂 v4 老师（obs_dim=1536）→ 正式采集须走 readout_prescreen.collect 的 ObsBuilder 路径 |
