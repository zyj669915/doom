# AI 科研提示词

这些是供本地研究者与 AI 使用的可复制任务文本，不是API应用、自动执行脚本、已安装的slash command或多agent配置。无需新增依赖，不预设模型供应商。

## 如何使用

1. 先读 [协作规范](../AGENTS.md) 和 [研究入口](../research/README.md)。
2. 将 [共同上下文](00-context.md) 加一个角色文件交给当前AI；支持本地文件读取的工具可直接读取，不支持时由用户粘贴内容和必要证据。
3. 补上任务ID、当前授权、文件范围、交互/墙钟预算与预期交付。未填写时只允许读相关文件并提出方案，不从历史计划取得执行权限。
4. 一次选一个主角色；只有真正独立的工作才考虑委派。文件本身不会启动子agent，也不要求使用多agent。
5. 完成后更新 [TASKS](../research/TASKS.md)、[STATUS](../research/STATUS.md) 与必要证据，使用 [交接提示词](08-handoff.md) 收尾。

## 角色选择

| 你的问题 | 提示词 | 典型交付 |
|---|---|---|
| 我们到底要做什么，下一步是什么？ | [01 科研统筹](01-research-lead.md) | 一个问题、一个主任务、依赖与停止边界 |
| 怎样设计一次有解释力的实验？ | [02 实验设计](02-experiment-design.md) | 可锁定协议草案、对照、预算、判定与分流 |
| 将任务实现为代码并验收 | [03 实现](03-implementation.md) | 最小差异、测试与未验实机边界 |
| 检查实现是否违背协议或有缺陷 | [04 复核](04-review.md) | 可复现缺陷、证据与验收遗漏，默认不改代码 |
| 已授权，按锁定协议执行 | [05 限额执行](05-controlled-execution.md) | 准入/运行/停止记录、不可覆盖的原始run |

| 查论文是否支持一个具体机制 | [07 文献核对](07-literature-check.md) | 页码/方法证据、模型差异、有限可实施启发 |

## 可直接使用的开场

```text
请先读取 experiment/AGENTS.md、experiment/prompts/00-context.md、
experiment/research/README.md、STATUS.md、TASKS.md。
使用 experiment/prompts/01-research-lead.md 的职责，判断当前唯一值得推进的任务。
本次仅允许本地只读分析；不要训练、运行游戏、上传资料或执行同步/提交。
不要从历史计划推断当前状态，结论请关联原始证据。
```

实现任务时把角色换为03，并明确允许修改范围和验收预算。当前下一研发项是T010，但此示例不授予实现或训练权限；以后始终读取任务板，不依赖本页这句历史快照。

## 维护规则

共同约束只维护在AGENTS和00-context；角色提示词只描述各自差异。提示词不得包含假成绩、私密凭据、虚构可执行命令、要求暴露内部思维链或无上限“直到成功”。需要的是简短决策依据、工具证据与可检验产物。给外部服务上传本地资料仍需用户明确授权，不能因复制提示词绕过隐私边界。
